# PCI Express Card PCB design project
-
Developed a mixed-signal PCB layout following strict placement strategies, prioritizing
thermal management for power stages, noise isolation for the analog input path (24-bit
ADC), and clear separation of high-speed digital domains. 

This project highlighted:
-Signal Integrity & Impedance Control
-Routing of high-speed differential interfaces, including USB_N/P and LVDS_OUT+/-,
ensuring strict length matching and signal quality
-Reduction of parasitic capacitance of the crystal oscillators
-Fabrication & Post-Processin
